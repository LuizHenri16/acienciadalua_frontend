# A Ciência da Lua - Frontend

**A Ciência da Lua** é uma plataforma de e-commerce dedicada à comercialização de materiais de ensino e aprendizagem, desenvolvida especialmente para atender às necessidades de estudantes e professores. O projeto visa facilitar o acesso a recursos educacionais de alta qualidade através de uma interface moderna, intuitiva e responsiva.

**Link do Site Protótipo para testes de UX/UI:** https://acienciadalua-frontend.vercel.app/

## 🚀 Tecnologias

Este projeto foi construído utilizando as seguintes tecnologias:

- **Next.js** - Framework React para produção.
- **React** - Biblioteca para construção de interfaces.
- **TypeScript** - Linguagem de programação com tipagem estática.
- **Tailwind CSS** - Framework CSS utilitário para estilização rápida.
- **Lucide React** - Coleção de ícones leves e bonitos.
- **React Spinners** - Componentes de carregamento para melhor UX.

## 🛠️ Estrutura do Projeto

A organização das pastas segue o padrão moderno do Next.js:

- `src/app`: Contém as rotas e páginas da aplicação (App Router).
- `src/components`: Componentes reutilizáveis organizados por funcionalidade (header, footer, home, product, etc.).
- `src/types`: Definições de interfaces e tipos TypeScript.
- `public`: Ativos estáticos como imagens e fontes.
