## Anti-Patterns Verdict

**Does this look AI-generated?** Partially — two clear tells are present.

**LLM assessment**: The hero-metric template ("9 anos" + small label "de experiência" + "UFRN" + small label) and the tiny uppercase eyebrow on the FAQ section ("DÚVIDAS FREQUENTES") are the two signals. The rest of the page avoids AI clichés well — no gradient text, no glassmorphism, no numbered sections, no sketchy illustrations. The marinho + turquoise/rose palette is distinctive.

**Deterministic scan (detect.mjs)**: 2 findings, both in `faqCard.tsx`:
- `side-tab` at line 35: `border-l-4` (open-state indicator on FAQ accordion — contextually justified, low concern)
- `layout-transition` at line 48: `transition: max-height` (performance issue on accordion animation)

## Overall Impression

A well-crafted brand vitrine with strong visual identity (marinho + turquoise/rose), excellent typographic discipline (Sora + Unkempt), and a genuine emotional anchor in the about section. The main weaknesses are templated landing-page patterns (hero metrics, eyebrow kicker) that clash with the otherwise authentic brand voice, and accessibility gaps (text contrast, duplicate DOM IDs).

## What's Working

1. **Brand identity through color & atmosphere** — The dark hero + teal/rose accent palette is genuinely distinctive and avoids both marketplace and institutional templates
2. **About section as emotional anchor** — Profa. Lua's photo, personal quote, and credential badges make "autoria" tangible
3. **Typographic discipline** — Sora for function, Unkempt exclusively in the brand name. No font leaks

## Priority Issues

### [P1] Hero-metric template in banner
- **What**: `bannerSection.tsx:84-102` — "9 anos" + "UFRN" as big-number/small-label metric blocks
- **Why**: Most recognizable AI landing-page cliché of 2024-2026. Undermines "autoria em primeiro lugar"
- **Fix**: Replace with narrative credential display ("Quase uma década ensinando Química") or integrate into about section
- **Command**: `$impeccable polish src/components/home/bannerSection.tsx`

### [P1] Tiny uppercase eyebrow on FAQ section
- **What**: `faqSection.tsx:21` — "DÚVIDAS FREQUENTES" in tiny uppercase tracking
- **Why**: The skill explicitly bans "eyebrow on every section" as AI grammar. Two sections with the pattern signals it
- **Fix**: Remove the eyebrow; the H2 "Perguntas Frequentes" stands fine alone
- **Command**: `$impeccable polish src/components/home/faqSection.tsx`

### [P1] Text contrast failure on light backgrounds
- **What**: `--color-texto-terciario` (#8888AA) on `bg-off-white` (#F7F5F0) ≈ 3.0:1 contrast — fails WCAG AA (4.5:1). Affects banner subtitle and FAQ description
- **Why**: Body text is not decorative. Students with vision differences or in low light will struggle. WCAG AA is minimum legal standard
- **Fix**: Darken to at least #6969A0 (~4.7:1 against off-white)
- **Command**: `$impeccable harden src/app/globals.css`

### [P2] Duplicate DOM ID (#como-funciona)
- **What**: Both `aboutSection.tsx:17` and `faqSection.tsx:13` use `id="como-funciona"`. Footer links "Sobre" and "FAQ" both point to `/#como-funciona` — FAQ link always scrolls to About
- **Why**: Functional bug — the FAQ link in the footer literally never works
- **Fix**: Unique IDs (`id="sobre"`, `id="faq"`) + update footer link targets
- **Command**: `$impeccable harden`

### [P2] Silent API error handling
- **What**: `page.tsx:15-17` — `getProducts().catch(() => [])` silently swallows all errors
- **Why**: Empty carousels with no message look broken. New visitors assume no products exist
- **Fix**: Show inline error message + retry button on failure
- **Command**: `$impeccable harden src/app/page.tsx`

### [P3] Carousel dots aria-label mismatch
- **What**: `productCarousel.tsx:103` — `aria-label={"Ver produto ${index + 1}"}` on scroll indicator dots
- **Why**: Screen reader users hear "Ver produto 3" and expect a product link, but get a position control
- **Fix**: `aria-label={"Ir para o slide ${index + 1}"}`
- **Command**: `$impeccable audit`

## Persona Red Flags

**Jordan (First-Timer)**: On API failure, sees empty section headings with no products and no error message. Would assume the site is broken. No search bar, no visible help beyond the footer FAQ. No skip-to-content link.

**Sam (Accessibility-Dependent)**: Text contrast fails WCAG AA on banner subtitle. Multiple `animate-pulse` with no `prefers-reduced-motion`. Carousel dot labels misleading. No skip link.

**Riley (Stress Tester)**: Network failure produces silent uncaught error. Duplicate DOM IDs cause `querySelector('#como-funciona')` to return unexpected element. Pulse animation on badge might trigger vestibular issues.

## Minor Observations
- `animate-pulse` on banner badge (`bannerSection.tsx:55`) has no `prefers-reduced-motion` fallback
- No skip-to-content link
- "ou" divider (`page.tsx:44-51`) is clever but the `font-black` weight feels heavy
- Carousel `overflow-y-visible` + `overflow-x-auto` may clip shadows per CSS spec

## Questions to Consider

2. Should carousels be replaced with grids for better product discoverability?
