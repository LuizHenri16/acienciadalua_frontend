## Design Context

This project uses the **impeccable** design workflow. Key references:

- **PRODUCT.md** — strategic context: register (`brand`), users, personality, design principles
- **DESIGN.md** — visual system: colors, typography, elevation, components, do's/don'ts
- **`.impeccable/design.json`** — machine-readable tokens + component snippets for live mode

Before making visual changes, read DESIGN.md. Before strategic decisions, read PRODUCT.md.
